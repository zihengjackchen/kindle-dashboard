# Verification record

Checked locally on 2026-10-04 using Python 3.13.8, Git for Windows POSIX shell,
curl 8.16.0, and ShellCheck 0.11.0.

- `python -m pytest -q`: **98 passed, 1 skipped**. The skipped test requires
  GNU wget, which is not installed on this host. The curl path performs real
  loopback HTTP requests against the application-backed test server.
- ShellCheck across all client scripts and `scripts/test-shell.sh`: no findings.
- Both Compose configurations pass `docker compose config --quiet` using Compose
  v5.6.0 (the standard file including its live collector profile). No engine is
  available locally, so this validates configuration rather than image execution.
- Shell syntax, KUAL XML/JSON, ZIP CRCs, LF script endings, and package contents
  checked. The install ZIP excludes generated caches, state, and diagnostics.
- Five 1236 × 1648 grayscale design previews generated by the application renderer;
  overview and market pages visually inspected. All preview data is marked SAMPLE.
- Native wake tests cover sleep/wake/exit ordering, duplicate events, locked
  guards, obsolete tickets, Stop/kill switch, sleep during settling and a real
  blocking mock LIPC subscriber. Wake restoration makes no HTTP requests.
- Per-page KUAL cache rotation, snapshot timestamp semantics, source schema and
  atomic publication failure behavior are tested.
- Contact persistence, preview exclusion, bounded telemetry, prior-fetch reporting,
  local battery samples and opt-out are tested.
- Provider tests cover timestamps, 24-hour crypto change, instrument mismatch,
  rate spacing, partial failure, stale retention and prevention of demo/live mixing.
- Live read-only smoke requests parsed successfully for Open-Meteo, Coinbase BTC
  statistics and the Twelve Data AAPL demo. This does not verify a user's market
  entitlements, location or TrueNAS host.
- Private setup packaging matches tokens without printing them; standard packages
  exclude private overrides. The release ZIP contains 26 entries with valid CRCs.
- TrueNAS exporter fixture tests preserve a faulted pool with unknown capacity
  and exclude raw serial numbers/alert text. Battery reports reject charging runs.
- One dependency deprecation warning: the installed Starlette test client warns
  that its httpx integration will eventually move to httpx2. Tests pass with the
  pinned httpx version; this does not affect the deployed image endpoint.

At this initial Windows checkpoint Docker image execution and GNU wget were not

display/KUAL interaction and suspend behavior remain unverified.

The included GitHub Actions workflow is configured to run Linux tests, ShellCheck,

remote workflow results must be checked separately after publication.

## NAS deployment, 2026-10-05

Built and started the image on TrueNAS SCALE 24.10.2.4 (amd64), Docker Engine
27.1.1 and Compose 2.29.1. Both the renderer and collector report healthy and
recover through a controlled restart/recreate. They run as UID 10001 with
read-only root filesystems, bounded memory, and restart policy `unless-stopped`.

The live LAN endpoint passed authentication rejection, health/status checks, and
PNG decoding/header/dimension checks for all five 1236x1648 pages. The real shell
client fetched all five pages from the deployed NAS and validated/cached them;
framebuffer drawing was mocked. No synthetic Kindle contact was recorded.

Live NAS health, BTC and ETH data were collected. Weather location and equity
provider credentials remain unconfigured. The TrueNAS host export was verified
through the native scheduled-task runner, with a 15-minute schedule. Existing
NAS applications remained running during installation.

Deployment exposed a Compose readiness error for a collector without a health
check. Added a bounded publication-age check and verified `up --wait` succeeds.
Older Linux ShellCheck also flagged ambiguous shell condition style; conditions
were rewritten as explicit `if` statements without changing the policy.

The full suite then passed inside a disposable Linux container on the NAS:
**100 passed**, no skips, one existing Starlette/httpx deprecation warning.
GNU wget, curl, and Linux ShellCheck were included in that validation container;
no test tools were installed into the NAS host or production containers.
The validation container was removed after completion.
